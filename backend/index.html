    Лабораторная работа №3: Документация бекенда

    Описание проекта

    Бекенд приложения для управления гостиницей, разработанный на Django REST Framework. Система предоставляет REST API для управления номерами, клиентами, проживаниями, сотрудниками и генерации квартальных отчётов.

    Технологический стек

    • Django 5.1.1 - веб-фреймворк для Python
    • Django REST Framework - инструментарий для создания REST API
    • drf-spectacular - генерация OpenAPI/Swagger документации
    • django-filter - фильтрация данных
    • django-cors-headers - обработка CORS запросов
    • PostgreSQL/SQLite - база данных

    Быстрый старт

    Установка зависимостей

    python3 -m venv .venv
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate  # Windows
pip install -r requirements.txt

    Настройка окружения

    Создайте файл .env в корне проекта:

    DJANGO_SECRET_KEY=your-secret-key
DEBUG=True
USE_SQLITE=True
ALLOWED_HOSTS=*
CORS_ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173

    Применение миграций

    python manage.py migrate

    Заполнение демо-данными (опционально)

    python manage.py seed_hotel

    Запуск сервера разработки

    python manage.py runserver

    API будет доступно по адресу http://127.0.0.1:8000/api/ Swagger документация: http://127.0.0.1:8000/api/docs/

    Структура проекта

    labLexa/
├── config/              # Настройки Django проекта
│   ├── settings.py      # Конфигурация приложения
│   ├── urls.py          # Главный URL роутинг
│   └── wsgi.py          # WSGI конфигурация
├── rooms/               # Приложение управления номерами
├── clients/             # Приложение управления клиентами
├── stays/               # Приложение управления проживаниями
├── employees/           # Приложение управления сотрудниками
├── reports/             # Приложение генерации отчётов
├── common/              # Общие утилиты
└── requirements.txt     # Python зависимости

    Основные возможности

    • 🏨 Управление номерами - CRUD операции с номерами, проверка свободных мест
    • 👥 Управление клиентами - работа с базой клиентов, поиск пересечений проживаний
    • 📝 Управление проживаниями - регистрация заездов и выездов, расчёт стоимости
    • 👷 Управление сотрудниками - управление персоналом и расписанием уборки
    • 📈 Отчёты - квартальные отчёты по доходам и загрузке номеров
