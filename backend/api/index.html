    API Endpoints

    Базовый URL

    Все API endpoints доступны по адресу: http://127.0.0.1:8000/api/

    Документация API

    • Swagger UI: /api/docs/
    • ReDoc: /api/redoc/
    • OpenAPI Schema: /api/schema/

    Номера (Rooms)

    Базовые операции

    • GET /api/rooms/ - список всех номеров
    • POST /api/rooms/ - создание нового номера
    • GET /api/rooms/{id}/ - детали номера
    • PUT /api/rooms/{id}/ - обновление номера
    • DELETE /api/rooms/{id}/ - удаление номера

    Фильтрация

    Параметры запроса: - room_type - тип номера (single, double, triple) - floor - этаж - is_active - активность номера

    Пример: 

    GET /api/rooms/?room_type=single&floor=2

    Дополнительные endpoints

    GET /api/rooms/{id}/clients/

    Получение списка клиентов в номере за период.

    Параметры: - start - начальная дата (YYYY-MM-DD) - end - конечная дата (YYYY-MM-DD)

    Пример: 

    GET /api/rooms/1/clients/?start=2024-01-01&end=2024-01-31

    GET /api/rooms/free-count/

    Получение сводки по свободным номерам.

    Ответ: 

    {
  "total_free_rooms": 5,
  "by_type": [
    {
      "room_type": "single",
      "label": "Одноместный",
      "count": 2
    },
    {
      "room_type": "double",
      "label": "Двухместный",
      "count": 3
    }
  ]
}

    Клиенты (Clients)

    Базовые операции

    • GET /api/clients/ - список всех клиентов
    • POST /api/clients/ - создание нового клиента
    • GET /api/clients/{id}/ - детали клиента
    • PUT /api/clients/{id}/ - обновление клиента
    • DELETE /api/clients/{id}/ - удаление клиента

    Фильтрация

    Параметры запроса: - city - фильтр по городу

    Пример: 

    GET /api/clients/?city=Москва

    Дополнительные endpoints

    GET /api/clients/count-by-city/

    Подсчёт клиентов по городу.

    Параметры: - city - название города

    Пример: 

    GET /api/clients/count-by-city/?city=Москва

    GET /api/clients/{id}/stays/

    История проживаний клиента.

    GET /api/clients/{id}/overlaps/

    Поиск клиентов с пересекающимися периодами проживания.

    Параметры: - start - начальная дата (YYYY-MM-DD) - end - конечная дата (YYYY-MM-DD)

    Проживания (Stays)

    Базовые операции

    • GET /api/stays/ - список всех проживаний
    • POST /api/stays/ - создание нового проживания
    • GET /api/stays/{id}/ - детали проживания
    • PUT /api/stays/{id}/ - обновление проживания
    • DELETE /api/stays/{id}/ - удаление проживания

    Фильтрация

    Параметры запроса: - client - ID клиента - room - ID номера - status - статус (active, completed) - room_number - номер комнаты

    Пример: 

    GET /api/stays/?status=active&room_number=101

    Дополнительные endpoints

    POST /api/stays/{id}/checkout/

    Выполнение выезда клиента.

    Тело запроса: 

    {
  "check_out": "2024-01-15"
}

    Ответ: Обновлённый объект проживания с рассчитанной стоимостью.

    Сотрудники (Employees)

    Базовые операции

    • GET /api/employees/ - список всех сотрудников
    • POST /api/employees/ - создание нового сотрудника
    • GET /api/employees/{id}/ - детали сотрудника
    • PUT /api/employees/{id}/ - обновление сотрудника
    • DELETE /api/employees/{id}/ - удаление сотрудника

    Дополнительные endpoints

    POST /api/employees/{id}/fire/

    Увольнение сотрудника.

    Ответ: Обновлённый объект сотрудника со статусом fired.

    PUT /api/employees/{id}/schedule/

    Обновление расписания уборки сотрудника.

    Тело запроса: 

    {
  "assignments": [
    {
      "floor": 1,
      "weekday": "mon"
    },
    {
      "floor": 1,
      "weekday": "wed"
    }
  ]
}

    GET /api/employees/who-cleans/

    Определение сотрудника, ответственного за уборку.

    Параметры: - client_id - ID клиента - weekday - день недели (mon, tue, wed, thu, fri, sat, sun)

    Пример: 

    GET /api/employees/who-cleans/?client_id=1&weekday=mon

    Отчёты (Reports)

    GET /api/reports/quarterly/

    Получение квартального отчёта.

    Параметры: - quarter - квартал (1-4) - year - год

    Пример: 

    GET /api/reports/quarterly/?quarter=1&year=2024

    Ответ: 

    {
  "period": {
    "quarter": 1,
    "year": 2024,
    "start": "2024-01-01",
    "end": "2024-03-31"
  },
  "clients_per_room": [
    {
      "room__id": 1,
      "room__number": 101,
      "client_count": 5
    }
  ],
  "rooms_per_floor": [
    {
      "floor": 1,
      "room_count": 10
    }
  ],
  "income_per_room": [
    {
      "room__id": 1,
      "room__number": 101,
      "total_income": 50000.00
    }
  ],
  "total_income": 500000.00
}

    Формат ответов

    Все ответы возвращаются в формате JSON. При ошибках возвращается статус код и описание ошибки:

    {
  "detail": "Описание ошибки"
}

    Коды статусов

    • 200 OK - успешный запрос
    • 201 Created - ресурс создан
    • 400 Bad Request - некорректный запрос
    • 404 Not Found - ресурс не найден
    • 500 Internal Server Error - внутренняя ошибка сервера
