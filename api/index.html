    Работа с API

    Конфигурация

    API сервис настроен в src/services/api.ts с использованием RTK Query.

    Базовый URL

    Настраивается через переменную окружения VITE_API_BASE_URL (по умолчанию: http://127.0.0.1:8000/api)

    Endpoints

    Номера (Rooms)

    useGetRoomsQuery(params?)

    Получение списка номеров с опциональной фильтрацией.

    Параметры: - room_type?: string - тип номера (single, double, triple) - floor?: number - этаж

    Пример: 

    const { data: rooms } = useGetRoomsQuery({ room_type: 'single' });

    useGetFreeRoomsQuery()

    Получение сводки по свободным номерам.

    useGetRoomClientsQuery({ roomId, start, end })

    Получение списка клиентов в номере за период.

    Клиенты (Clients)

    useGetClientsQuery(params?)

    Получение списка клиентов.

    Параметры: - city?: string - фильтр по городу

    useCreateClientMutation()

    Создание нового клиента.

    Пример: 

    const [createClient] = useCreateClientMutation();
await createClient({ 
  passport_number: '1234',
  last_name: 'Иванов',
  first_name: 'Иван',
  city: 'Москва'
});

    useGetClientStaysQuery(clientId)

    Получение истории проживаний клиента.

    useGetOverlappingClientsQuery({ clientId, start, end })

    Получение клиентов с пересекающимися периодами проживания.

    Проживания (Stays)

    useGetStaysQuery(params?)

    Получение списка проживаний.

    Параметры: - status?: string - статус (active, completed)

    useCreateStayMutation()

    Создание нового проживания.

    useCheckoutStayMutation()

    Выполнение выезда клиента.

    Пример: 

    const [checkout] = useCheckoutStayMutation();
await checkout({ stayId: 1, check_out: '2024-01-15' });

    Сотрудники (Employees)

    useGetEmployeesQuery()

    Получение списка сотрудников.

    useCreateEmployeeMutation()

    Создание нового сотрудника.

    useFireEmployeeMutation()

    Увольнение сотрудника.

    useUpdateScheduleMutation()

    Обновление расписания уборки сотрудника.

    useWhoCleansQuery({ clientId, weekday })

    Определение сотрудника, ответственного за уборку.

    Отчёты (Reports)

    useGetQuarterlyReportQuery({ quarter, year })

    Получение квартального отчёта.

    Пример: 

    const { data: report } = useGetQuarterlyReportQuery({ 
  quarter: 1, 
  year: 2024 
});

    Кэширование и инвалидация

    RTK Query автоматически кэширует результаты запросов. При мутациях соответствующие теги инвалидируются:

    • ['Rooms'] - при операциях с номерами
    • ['Clients'] - при операциях с клиентами
    • ['Stays'] - при операциях с проживаниями
    • ['Employees'] - при операциях с сотрудниками
    • ['Reports'] - при операциях с отчётами

    Состояния запросов

    Каждый хук возвращает: - data - данные ответа - isLoading - флаг загрузки - error - объект ошибки (если есть) - refetch - функция для повторного запроса

    Пример использования: 

    const { data, isLoading, error } = useGetRoomsQuery();

if (isLoading) return <CircularProgress />;
if (error) return <div>Ошибка загрузки</div>;
return <div>{/* отображение данных */}</div>;
